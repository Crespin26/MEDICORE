# MediCore mobile

Socle Flutter Android/iOS. L’écran d’accueil indique le statut de préparation ; aucune connexion API ni donnée clinique n’est encore intégrée.

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

La compilation iOS nécessite macOS et Xcode. Les identifiants `com.medicore` sont provisoires et doivent être validés avant publication.
